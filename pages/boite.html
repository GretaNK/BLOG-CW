Le modèle de boîte

Lorsqu'on crée une page web, chaque élément HTML occupe un certain espace. Pour gérer cet espace et organiser correctement les éléments, le CSS utilise ce qu'on appelle le modèle de boîte, ou Box Model en anglais.

Le modèle de boîte est un concept fondamental du CSS. Il permet de comprendre comment les éléments sont dimensionnés et comment les espacements sont calculés autour de ceux-ci.
En CSS, chaque élément est représenté par une boîte rectangulaire composée de quatre parties principales : le contenu, le padding, la bordure et la marge.

Les quatre parties du modèle de boîte/h2>

Le contenu représente la partie centrale de la boîte. Il peut s'agir d'un texte, d'une image ou d'un autre élément HTML.
Les propriétés width et height permettent de définir les dimensions de cette zone avec le modèle de boîte classique.

✦

Conseil : pensez à utiliser box-sizing: border-box pour mieux maîtriser les dimensions de vos éléments, bordures et espacements.

Exemple à retenir

La dimension de notre conteneur

CSS 
.box { 
    width: 200px; 
    padding: 20px; 
    border: 5px solid black; 
    margin: 10px; 
}

À retenir : La largeur totale de la boîte, sans compter les marges, sera 200 + 20 + 20 + 5 + 5 = 250 pixels.
Si nous prenons également en compte les marges extérieures, l'espace horizontal occupé sera de 270 pixels.
Il est donc important de comprendre que la largeur définie avec width ne correspond pas toujours à la largeur finale de l'élément.

La propriété box-sizing

Pour faciliter la gestion des dimensions, le CSS propose la propriété box-sizing.
En utilisant la valeur border-box, la largeur et la hauteur définies incluent directement le contenu, le padding et les bordures.
