Responsive Design

Aujourd'hui, les internautes consultent les sites web depuis différents appareils : ordinateurs, tablettes et smartphones. Chaque appareil possède une taille d'écran différente, ce qui peut influencer l'affichage d'une page web.
C'est pourquoi il est essentiel de créer des sites capables de s'adapter automatiquement à ces différentes dimensions.
Cette approche est appelée Responsive Web Design, ou conception web adaptative en français.

Le Responsive Design consiste à concevoir une interface qui ajuste sa mise en page, ses images, ses textes et ses éléments de navigation en fonction de l'espace disponible.
L'objectif est de garantir une expérience utilisateur agréable, quel que soit l'appareil utilisé.

Les Media Queries : adapter le CSS selon l'écran

Les Media Queries sont l'un des outils les plus importants du Responsive Design.
Elles permettent d'appliquer des règles CSS uniquement lorsque certaines conditions sont remplies, notamment en fonction de la largeur de la fenêtre d'affichage.
Pour cela, nous utilisons la règle @media.

✦

Conseil : adoptez une approche mobile first et construisez vos mises en page en commençant par les petits écrans.

Exemple à retenir

Adapter un visuel par ecran

CSS 
body { 
    background-color: white; 
} 
@media (max-width: 600px) { 
    body { 
        background-color: lightblue; 
} 
}

À retenir : lorsque la largeur du viewport est supérieure à 600 pixels, l'arrière-plan reste blanc. Lorsque la largeur est inférieure ou égale à 600 pixels, l'arrière-plan devient bleu clair.
Nous pouvons donc modifier l'apparence d'une page en fonction de la largeur disponible.

Les unités relatives dans le Responsive Design

Pour créer des mises en page adaptatives, il est préférable de ne pas utiliser uniquement des dimensions fixes en pixels.
Les unités relatives, comme %, rem, vw et fr, permettent de créer des éléments plus flexibles.

Adapter le menu de navigation

Sur un ordinateur, nous disposons généralement de suffisamment d'espace pour afficher les liens du menu horizontalement.

Sur un smartphone, cet espace est plus limité. Nous pouvons donc modifier leur disposition à l'aide d'une Media Query.
