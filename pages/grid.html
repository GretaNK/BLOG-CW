CSS Grid

Lorsqu'on développe un site web, il est essentiel de pouvoir organiser les différents éléments de manière claire et harmonieuse.
Après avoir découvert Flexbox, qui permet principalement de disposer des éléments sur un seul axe, nous allons maintenant découvrir CSS Grid.

CSS Grid est un système de mise en page qui permet de créer des structures composées de lignes et de colonnes. Il est particulièrement utile pour organiser les différentes sections d'un site, créer des galeries d'images ou afficher des articles de blog sous forme de grille.

Contrairement à Flexbox, CSS Grid permet de contrôler simultanément la disposition horizontale et verticale des éléments.

Comment fonctionne CSS Grid ?/h2>

Pour utiliser CSS Grid, nous devons commencer par définir un conteneur en grille.
Il suffit d'appliquer la propriété display: grid; à un élément parent.

Les éléments enfants directs deviennent alors des éléments de la grille.
Cependant, pour organiser leur disposition, nous devons définir le nombre et la taille des colonnes ou des lignes.

✦

Conseil : utilisez grid-template-columns: repeat() pour créer facilement des colonnes régulières et gagner du temps dans vos mises en page.

Exemple à retenir

Connecter notre fichier CSS

CSS 
.articles { 
    display: grid; 
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); 
    gap: 20px; 
} 
.article { 
    padding: 20px; 
    background-color: #f5f5f5; 
    border: 1px solid #ccc; 
    border-radius: 10px; 
    text-align: center; 
}

À retenir : dans cet exemple, les articles sont automatiquement organisés en colonnes en fonction de l'espace disponible.

Quelle est la différence entre Flexbox et Grid ?

Même si Flexbox et Grid permettent tous les deux d'organiser les éléments d'une page web, ils répondent à des besoins différents.

Flexbox : Fonctionne principalement sur un axe , Idéal pour aligner des éléments, Pratique pour les menus et les boutons, Organisation flexible selon le contenu

Grid : Fonctionne sur deux axes, Idéal pour créer des mises en page structurées, Pratique pour les galeries et les articles, Organisation en lignes et colonnes

Ces deux systèmes sont complémentaires et peuvent être utilisés ensemble dans un même site.
