Introduction au CSS

Les quelques principes essentiels pour donner du rythme, de la personnalité et une vraie cohérence visuelle à tes pages web.

L Écrit par Lorem Ipsum
5 novembre 2026 · 6 min de lecture

Lorsqu'on souhaite créer une page web, on commence généralement par utiliser le HTML, qui permet de structurer le contenu d'un site : titres, paragraphes, images, liens, etc. Cependant, pour rendre cette page plus attractive et lui apporter une véritable identité visuelle, nous utilisons le CSS.

Qu'est le CSS

Le CSS (Cascading Style Sheets), ou « feuilles de style en cascade » en français, est un langage qui permet de définir l'apparence et la mise en forme des éléments d'une page web. Grâce au CSS, il est possible de personnaliser de nombreux aspects d'un site, notamment les couleurs, les polices de caractères, les tailles, les espacements ou encore le positionnement des éléments.

Il existe plusieurs façons d'intégrer du CSS dans une page web. Les règles de style peuvent être directement écrites dans le fichier HTML ou placées dans un fichier CSS externe.

✦

Conseil : la méthode la plus recommandée consiste à utiliser un fichier CSS séparé. Cette approche permet de mieux organiser son code, de séparer la structure HTML de la présentation visuelle et de faciliter la maintenance du site.

Exemple à retenir

Une carte simple avec CSS

CSS 
<head> 
<link rel="stylesheet" href="style.css"> 
</head>

À retenir : <link> permet de lier une ressource externe à notre document HTML.

rel="stylesheet" indique que le fichier lié est une feuille de style CSS. href="style.css" précise le chemin vers notre fichier CSS.

Il est important de vérifier que le chemin indiqué dans href correspond bien à l'emplacement de notre fichier CSS. Une fois cette connexion établie, notre page HTML est prête à recevoir ses premiers styles !
