Les unités de mesure

Lorsque nous créons une page web, nous devons régulièrement définir la taille des éléments, les espacements, les marges ou encore la taille des textes.

Le CSS utilise différentes unités de mesure, qui permettent de contrôler les dimensions et la disposition des éléments HTML.
Il existe deux grandes catégories d'unités : les unités absolues et les unités relatives.

Les unités absolues

Les unités absolues représentent des dimensions fixes, qui ne dépendent pas directement de la taille de l'élément parent.

Le pixel est l'une des unités les plus utilisées en CSS. Il permet de définir une dimension précise.

✦

Conseil : la méthode la plus recommandée consiste à utiliser un fichier CSS séparé. Cette approche permet de mieux organiser son code, de séparer la structure HTML de la présentation visuelle et de faciliter la maintenance du site.

Exemple à retenir

Connecter notre fichier CSS

CSS 
<head> 
<link rel="stylesheet" href="style.css"> 
</head>

À retenir : <link> permet de lier une ressource externe à notre document HTML.

Le CSS propose également d'autres unités

cm : centimètres.
mm : millimètres.
in : pouces.
pt : points.
pc : picas.

Les unités relatives

Contrairement aux unités absolues, les unités relatives dépendent d'une autre valeur, comme la taille de la police, les dimensions d'un élément parent ou celles de la fenêtre du navigateur. Elles sont particulièrement utiles pour créer des sites responsive, capables de s'adapter aux différents formats d'écran.

Quelle unité choisir ?

Unité et son utilisation courante ↓
px : Bordures, dimensions précises
% : Largeurs adaptatives
em : Espacements liés à la taille du texte
rem : Tailles de police et espacements cohérents
vw : Dimensions liées à la largeur de l'écran
vh : Dimensions liées à la hauteur de l'écran
dvh : Hauteur visible dynamique sur mobile

Il n'existe pas une seule unité idéale pour toutes les situations. L'objectif est de choisir celle qui correspond le mieux au comportement souhaité.
