Les sélecteurs CSS

Maintenant que notre fichier CSS est correctement relié à notre page HTML, nous pouvons commencer à appliquer nos premiers styles.

Un sélecteur permet d'indiquer à quels éléments HTML nous souhaitons appliquer un style. Il est donc essentiel pour personnaliser l'apparence de notre page web. Pour cela, nous allons utiliser les sélecteurs CSS.

Comprendre la syntaxe CSS

Une règle CSS se compose de deux parties principales Le sélecteur : il indique quel élément HTML nous souhaitons modifier. Le bloc de déclarations : il contient les propriétés CSS et leurs valeurs, qui définissent l'apparence de l'élément.

Il existe plusieurs types de sélecteurs permettant de cibler les éléments HTML de différentes manières.
Le sélecteur par balise HTML
Ce sélecteur permet de sélectionner tous les éléments portant le même nom de balise.
Le sélecteur par identifiant (ID)
Le sélecteur ID permet de cibler un élément HTML possédant un identifiant spécifique. En CSS, il est précédé du symbole #.
Le sélecteur par classe (Class)
Le sélecteur de classe permet d'appliquer le même style à plusieurs éléments HTML. En CSS, il est précédé d'un point ..

✦

Conseil : contrairement à un ID, une classe peut être utilisée sur plusieurs éléments HTML. C'est particulièrement pratique lorsqu'on souhaite réutiliser les mêmes styles à différents endroits de notre site.

Exemple à retenir

Selecteur html

CSS 
p { 
    color: #333; 
    line-height: 1.3; 
}

À retenir : Dans cet exemple : p est le sélecteur. Il cible tous les paragraphes de notre page HTML.
color: #333; définit la couleur du texte en gris foncé. line-height: 1.3; définit l'espacement vertical entre les lignes du texte à 1,3 fois la hauteur de la police.
Les accolades { } permettent de regrouper les déclarations CSS. Chaque déclaration est composée d'une propriété et d'une valeur, séparées par deux-points : et terminées par un point-virgule ;.

Pour résumer

p : sélectionne tous les paragraphes.
#identifiant : sélectionne un élément grâce à son ID.
.classe : sélectionne tous les éléments possédant cette classe.
* : sélectionne tous les éléments HTML.
